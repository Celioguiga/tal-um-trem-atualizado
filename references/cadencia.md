# Cadência — Ritmo Semanal de Conteúdo

## Horário Fixo
- Criação diária: 08h–09h

## Grade Semanal
| Dia | Pilar | Canal | Formato |
|-----|-------|-------|---------|
| Segunda | Avaliação / planejamento | — | Revisão interna |
| Terça | RNFG Decodifica | Instagram (Reels) + YouTube | Reels 20-30s + Vídeo 6-12min |
| Quarta | Na Sala de Aula / Por Que Funciona | Instagram (Carrossel) | 5-7 cards |
| Quinta | O Que É RNFG / Nos Bastidores | Facebook + Newsletter | Post + texto |
| Sexta | Lançamentos e Produtos | Instagram + Blog | Post + artigo |
| Sábado | Engajamento leve | Instagram Stories | Enquetes / Q&A / votação |
| Domingo | — | — | Descanso |

## Série-Carro-Chefe
- **"RNFG Decodifica"** — toda terça, no mesmo horário
- Aplica RNFG a uma música ocidental conhecida
- Gera 1 Reels + 1 YouTube (curto)
- Rode toda semana para criar hábito de audiência

## Regras de Ritmo
- Nunca pular uma sexta de lançamento sem aviso prévio
- Uma campanha nova a cada 2 semanas (alternar com RNFG Decodifica)
- Revisar ângulos usados no domingo para não repetir na semana seguinte
